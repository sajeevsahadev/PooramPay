# PooramPay — Release Notes

User-facing notes for each release. The **"Play — What's new"** block is ready to
paste into Google Play Console (keep each language ≤ 500 characters).

---

## v1.1 — 2026-10-04 (closed testing · version code 2)

**Highlights**
- 📍 **Find clubs near you** and send a request to **join** — the committee admin
  approves you and picks your role.
- 🔒 **Public or private clubs** — new clubs are private by default; turn on
  "Let people find & join this club" in Setup to be discoverable.
- 👤 **Richer profile** — add a photo, nickname, about, date of birth, gender;
  country is detected automatically.
- 🌐 **Public club page** — publish your committee's signed accounts to a
  shareable page at `poorampay.com/c/your-club`, found on Google.
- 📊 Interactive dashboard charts and a cleaner, mobile-first layout.
- 🐛 **Fixed:** the app now opens full-screen without a browser address bar
  (built from `www.poorampay.com` so domain verification passes).
